# Verification checklist: Steal a Brainrot, every brainrot

**Entity:** Steal a Brainrot, place ID 109983668079237
**Experience URL:** https://www.roblox.com/games/109983668079237/Steal-a-Brainrot
**Publisher:** BRAZILIAN SPYDER (group 35815907, owner SpyderSammy), verified badge

## Access path a tester follows

1. Open the experience URL above and confirm the creator reads BRAZILIAN SPYDER with a verified badge. Reject any near titled place, in particular Steal The Brainrot Base, Become a Brainrot and the New Players Servers place.
2. Join a server and open the in game Index. The Index lists indexable brainrots with rarity and base income per second. This is the tier 0 check and it settles every row on its own.
3. For a row whose route is marked retired, the Index still shows the entry; obtainability is checked at the machine or event, not in the Index.
4. For Red Carpet rows, stand at the carpet and confirm the entry walks past and is purchasable.

## Prerequisites

- A Roblox account. No age or premium gate on entry.
- Enough in game money to buy the entry being checked, or a server where it can be observed on the carpet without purchase.
- Rows gated on Admin Abuse can only be checked while an Admin Abuse window is live.
- Rows gated on Robux or on merchandise cannot be checked without spending; mark those rows as not checkable rather than passing them.

## How to read a line

Each line takes under a minute: find the name in the Index, compare rarity and base income, then compare the route. A mismatch on any of the three is a fail and should be recorded with the figure you actually saw.
