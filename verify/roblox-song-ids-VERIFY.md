# Verification checklist: Roblox song IDs

Entity: Roblox Creator Store audio catalogue, https://create.roblox.com/store/audio
Permalink: /guides/roblox-song-ids/

## Access path a tester follows

1. No Roblox account is needed for the desk check. All three endpoints below answer an anonymous browser request.
2. Asset record: open https://create.roblox.com/store/asset/ID and read the title and creator.
3. Machine record: open https://economy.roblox.com/v2/assets/ID/details and read Name and AssetTypeId. AssetTypeId must be 3 for audio.
4. Public availability: open https://assetdelivery.roblox.com/v2/assetId/ID. A location in the response means Roblox serves the file to an unauthenticated request. An errors block means it does not.
5. Catalogue metadata: open https://apis.roblox.com/toolbox-service/v1/items/details?assetIds=ID for the title, artist and genre Roblox files the track under.

## Prerequisites

- No account, no Robux and no level gates for the desk check.
- An in-game confirmation additionally needs an experience that supplies a boombox, radio or music panel that accepts a typed ID. No such item is portable between experiences.
- A row passes only if the title on the asset page still matches the Song column and the delivery endpoint still returns a location.
