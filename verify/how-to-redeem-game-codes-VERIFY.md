# Verification checklist: how to redeem game codes

Access path a tester follows: open each destination in the row, sign in to a throwaway account for that platform, and walk the named buttons in order without using search. A row passes only if every named button exists with the name recorded.

Entity URL: https://www.roblox.com/redeem

Prerequisites: a Roblox account, a Microsoft account, a PlayStation Network account, a Nintendo Account that has opened the eShop on a console at least once, an Epic Games account, a HoYoverse account with a Genshin Impact character created, and a GOG account. A Samsung Galaxy device is needed for one row. No purchase is required to reach any redemption screen.

Each line should take under a minute. Check the button names, not the outcome.

## Why a code fails, ordered by how often it actually happens

[ ] The code has expired  -> expected: Stop trying. An expired code cannot be revived by retyping it. Roblox states plainly that a promo code past its window cannot be redeemed. Go back to the publisher channel and take a current one.  | evidence: https://en.help.roblox.com/hc/en-us/articles/360029650831-How-Do-I-Redeem-a-Promo-Code https://help.starstable.com/hc/en-us/articles/360001374060-Redeem-codes-How-do-I-redeem-a-code | gates: none | confidence: confirmed
[ ] Wrong case or a mistyped character  -> expected: Paste rather than type, and delete any space before or after. Roblox lists the usual confusions as zero for the letter O, one for capital I, two for Z, five for S, six for G or Q, and eight for B. Nintendo download codes never contain O, I or Z at all.  | evidence: https://en.help.roblox.com/hc/en-us/articles/115005566223-How-to-redeem-and-spend-your-Gift-Card https://en-americas-support.nintendo.com/app/answers/detail/a_id/22429/~/how-to-redeem-a-download-code-on-nintendo-eshop | gates: none | confidence: confirmed
[ ] Already redeemed on this account  -> expected: Check the inventory category or the in game mail before assuming failure. Roblox virtual item codes redeem once per account and PlayStation voucher codes are single use across all accounts.  | evidence: https://en.help.roblox.com/hc/en-us/articles/360000316606-How-to-Redeem-Toy-Virtual-Item-Codes https://www.playstation.com/en-gb/support/store/redeem-ps-store-voucher-code/ | gates: none | confidence: confirmed
[ ] Signed in to the wrong account  -> expected: Sign out, sign in to the receiving account, and redeem again if the code is still unused. Xbox Support cannot move a redeemed code to another Microsoft account, and PlayStation cannot transfer content between accounts.  | evidence: https://support.xbox.com/en-GB/help/subscriptions-billing/redeem-codes-gifting/redeem-prepaid-codes https://en.help.roblox.com/hc/en-us/articles/360029650831-How-Do-I-Redeem-a-Promo-Code | gates: none | confidence: confirmed
[ ] A level or progress gate  -> expected: Play on and try again once the account has progressed. Genshin Impact is widely reported to require Adventure Rank 10 for most codes, with a small set of exceptions. That gate is not stated on the redemption page itself.  | evidence: https://www.gamesradar.com/genshin-impact-codes-redeem/ | gates: Varies by game | confidence: reported
[ ] The code only takes on a fresh server  -> expected: Leave the experience, rejoin, and submit again before anything else. This is reported repeatedly for Roblox experiences after an update and is confirmed by no publisher, so treat it as a cheap thing to try rather than a rule.  | evidence: https://www.pcgamesn.com/grow-a-garden/codes | gates: none | confidence: reported
[ ] Region lock  -> expected: Check the account region against the code. Xbox requires the Microsoft account region to match, and PlayStation requires the voucher region to match. Roblox is the exception and states its codes redeem worldwide with the value converted to your local currency.  | evidence: https://support.xbox.com/en-GB/help/subscriptions-billing/redeem-codes-gifting/redeem-prepaid-codes https://www.playstation.com/en-gb/support/store/redeem-ps-store-voucher-code/ | gates: none | confidence: confirmed
[ ] The code belongs to a different game  -> expected: Check the code against the game named at its source. Codes for one experience routinely appear on lists for its clone, and Microsoft warns that publisher codes which look like platform codes must go through the publisher's own store instead.  | evidence: https://support.xbox.com/en-GB/help/subscriptions-billing/redeem-codes-gifting/redeem-prepaid-codes https://www.pcgamesn.com/grow-a-garden/codes | gates: none | confidence: confirmed
