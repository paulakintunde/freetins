## Best GBA emulator for Windows and Mac

**mGBA (free, open source, best overall).** The accuracy benchmark. It emulates the solar sensor, tilt sensor, rumble and Game Boy Camera, links up to four instances in separate windows for local multiplayer, and runs on Windows, macOS and Linux plus 3DS, Wii and Switch ports. Note that the current stable release is **0.10.5** from **March 8, 2025**; version 0.11.0, with a rewritten link cable and netplay layer, is still in development. Nightly builds exist if you want that work now.

**RetroArch with the mGBA core (free).** Identical emulation quality inside a frontend that also handles your SNES, Genesis and PS1 libraries, with shaders, netplay and achievements. Install RetroArch, then grab the **mGBA** core from the core downloader.

**VisualBoyAdvance-M (free, legacy).** The last release, **2.2.3**, shipped in **October 2024**, and the emulation wiki says outright that it "is not updated as often these days and is falling behind in terms of accuracy and performance compared to mGBA". It keeps one real advantage: **joybus support for GameCube-to-GBA connectivity**, for *Four Swords Adventures* and *Crystal Chronicles*. Use it for that only. The original **VisualBoyAdvance** without the -M is abandonware from 2004.

**SkyEmu (free, open source).** At **v5** (February 2025) with Windows, macOS, Linux and Android builds plus a web version that runs GBA in a browser tab with nothing installed. Useful on a locked-down laptop or a Chromebook.

**On Mac, skip OpenEmu.** Still the prettiest frontend, but its last tagged release is **2.4.1** and it ships Intel-only binaries. On Apple Silicon in 2026, use mGBA or RetroArch.

**no$gba (Windows, free)** is only worth it if you are a ROM hacker who needs the debugger.

## How to set up Pizza Boy A on Android

1. Install **Pizza Boy A Basic** (free) or **Pizza Boy A Pro** ($5.99) from the **Google Play Store**.
2. Using the **Files** app, create a folder called **GBA** in Internal Storage.
3. Put your `.gba`, `.zip` or `.7z` files in that folder. Dump them from your own cartridges (see the legal section).
4. **BIOS is optional.** Pizza Boy runs games on a built-in high-level BIOS. If you have dumped the real 16KB `gba_bios.bin` from your own console, go to **Settings, then Advanced, then Custom BIOS** and point it at the file. It fixes the boot animation and a few edge cases.
5. Open Pizza Boy, tap the **folder icon**, grant storage access when Android asks, and open your GBA folder.
6. Tap a game to launch it.
7. Tap the screen, then the **menu icon**, then **Save State** to create a restore point.
8. For a controller, open **Settings, then Input, then External controller** and map each button. Our best controllers guide covers which pads pair cleanly with Android.
9. In Pro, turn on **Settings, then Backup, then Google Drive** so saves survive a new phone.

## How to set up Delta on iPhone

1. Open the **App Store**, search **Delta**, install it. It is from Testut Tech and it is free. Do not sideload, and ignore any site offering a Delta IPA.
2. Save your `.gba` file into the **Files** app, under **On My iPhone** or iCloud Drive. Delta accepts `.gba` for GBA, `.gb` and `.gbc` for Game Boy, and `.nds` for DS.
3. Open Delta and tap the **+ button** in the top right.
4. Select the `.gba` file. It appears under Game Boy Advance in your library.
5. **No BIOS is needed for GBA.** Delta only asks for BIOS files for Nintendo DS, and skipping those costs you the DS home screen and dual-slot GBA functionality, nothing more.
6. Tap the game to play. Pause with the **menu button**, then **Save State** or **Load State**.
7. Turn on **Delta Sync** in Settings and connect Google Drive or Dropbox so saves survive a new iPhone.
8. Pair a PlayStation, Xbox or MFi controller in **iOS Settings, then Bluetooth**, then assign it under **Delta, Settings, Controllers**.
9. For cheats, pause, tap **Cheat Codes**, pick the format (GameShark, Action Replay or Code Breaker) and paste. Our Pokemon Emerald cheats list is formatted for this.

## Why is my GBA emulator lagging, losing saves or ignoring my controller?

**Lag and stutter.** GBA is a 2001 handheld, so raw power is almost never the cause. Turn off shaders and upscaling filters first, then set frame skip manually to 0 instead of auto. In RetroArch, switch the video driver to Vulkan on Android or Metal on Mac and turn **Runahead** off. On laptops, plug the charger in, because battery-saver modes throttle the GPU hard.

**Crackling audio.** Raise the audio latency slider (64ms is a safe start) rather than lowering it. Crackle means the buffer is too small.

**Saves have vanished.** The most common Android complaint in 2026, and it is usually storage permissions rather than a bug. Scoped storage can revoke an app's folder access after an update or a phone migration. Check three things: that **All files access** is granted in Android Settings, that your games are in Internal Storage rather than a removed SD card, and that the `.sav` file sits beside the `.gba` file with an identical filename. Then turn on cloud backup.

**In-game saves work but save states do not load.** States are tied to the exact emulator build and often the exact ROM, so an update can break them. Use in-game saves for real progress and states for convenience.

**Controller will not pair.** Pair the pad in your phone or computer's Bluetooth settings **before** opening the emulator, not after. If it connects but does nothing, map the buttons manually, because auto-detection guesses wrong on third-party pads. On iOS only one app captures a controller at a time, so force-close other games. If input feels delayed, use a USB-C cable and the latency disappears.

**White screen on boot.** The file is corrupt, or it is a large ROM hack the emulator cannot handle. Re-dump the cartridge. Delta's own documentation gives the same advice.

## FAQ: GBA emulators

**What is the best GBA emulator in 2026?**
mGBA is the strongest desktop starting point and Delta is the simplest iPhone and iPad option. On Android, compare the current official listings for Pizza Boy, Lemuroid and other maintained choices because price and feature availability can change.

**Can I use a GBA emulator on iPhone without jailbreaking?**
Yes. Apple changed App Review Guideline 4.7 on April 5, 2024 to permit retro console emulators worldwide, and Delta launched on the App Store on April 17, 2024. Delta, RetroArch, Provenance, Linking Boy and Folium are all normal App Store downloads. You no longer need AltStore, a developer certificate or a jailbreak.

**Is downloading a GBA emulator legal?**
Emulator software and game files are separate legal questions, and the rules vary by country. Use official emulator downloads and only game files you are entitled to use; obtain local legal advice if you need a definitive answer for cartridge backups.

**Which GBA emulator supports link cable for Pokemon trading?**
Linkboy on Android and Linking Boy on iOS, both from Pixel Respawn LLC, do link cable emulation for up to four players over local network or on one device. Pizza Boy A Pro also supports local and Wi-Fi multiplayer. On desktop, mGBA links up to four instances and VisualBoyAdvance-M adds GameCube joybus support.

**Do I need a BIOS file to play GBA games?**
Usually not. mGBA, Delta and Pizza Boy all include a high-level BIOS replacement that runs almost the entire commercial library. A real 16KB GBA BIOS improves the boot animation and a handful of edge cases. If you want one, dump it from your own console rather than downloading it, since the file is Nintendo copyright.

**Why did my save file disappear on Android?**
Almost always storage permissions rather than a bug. Android's scoped storage rules can revoke an emulator's folder access after an update or a phone migration. Grant All files access in Android Settings, keep games in Internal Storage rather than a removable SD card, and check the `.sav` file sits beside the `.gba` file with the same name.

**Is there an official mGBA app for Android or iOS?**
No. The mGBA FAQ states that nobody on the project is a mobile developer and there is no official port. The mGBA core is available inside RetroArch on both Android and iOS, which gives you the same emulation quality in a different interface.

**Can I play GBA games legally without any ROMs?**
Yes. Nintendo Switch Online + Expansion Pack includes a licensed Game Boy Advance catalogue on supported Switch hardware. Original cartridges on compatible hardware are another route. Check Nintendo and hardware makers for current availability and pricing.

**Is GBA4iOS still worth installing?**
No. It has been unmaintained for around a decade and its creator, Riley Testut, replaced it with Delta. Sites offering GBA4iOS IPA files are unofficial re-signing services with no link to the original project. Install Delta from the App Store: it is free, open source, and does everything GBA4iOS did.

**What is the best free GBA emulator for Android?**
Pizza Boy A Basic. It uses the same engine as the paid Pro version, its listing states explicitly that it has no advertising, and it was updated on May 15, 2026. Lemuroid is the alternative if you want open source with automatic save handling. Avoid free emulators that show ads mid-game.
