## The exact 24-key target is too narrow

A compact grid of 24 mechanical keys can handle movement, modifiers and a layer of actions. That does not make every 24-key board a good gaming keypad. Many exact-count products are programmable keypads built for shortcuts, point-of-sale work or industrial control. They may have durable switches but no thumb control, wrist support, game profiles or useful rollover information.

Current dedicated gaming keypads often use 25 to 32 inputs because the layout includes a thumb pad, scroll wheel or modifiers. The better buying question is therefore not “does it have exactly 24 keys?” It is “can my hand reach the controls I need, with software and switches I trust?”

This is one part of the broader [PC and console gear compatibility guide](/gear/pc-and-console/), where platform support comes before a product label.

## Start with the action map

List the controls used in the game before looking at products:

- Four movement directions.
- Sprint, crouch, jump and interact.
- Reload or primary action.
- Ability slots or hotbar numbers.
- Map, inventory and communication.
- One or two modifiers for a second layer.

Twenty-four keys may be enough when modifiers are comfortable. An MMO, simulation or editing-heavy game may need more. A thumb stick or D-pad can free four finger keys, but some players prefer keyboard-style WASD movement. Choose the layout around the game and hand, not an attractive photo.

## Mechanical, optical and mecha-membrane

### Conventional mechanical switches

These use individual switch mechanisms and may allow keycap or switch replacement. Switch color is not a universal standard across brands, so compare actuation force, travel, noise and whether the board is hot-swappable.

### Analog optical switches

Some gaming keypads can report position through part of the key travel or provide adjustable actuation. Games and software must support the intended behavior, and the extra control is not automatically useful for every action.

### Mecha-membrane

Razer describes the Tartarus V2 as mecha-membrane: a membrane mechanism designed with a tactile click-like response. It is not the same as a conventional replaceable mechanical switch. The distinction matters if repairability or a specific switch feel is the reason for buying.

## Current alternatives to a generic 24-key pad

### Razer Tartarus V2

Razer currently lists 32 programmable inputs, an eight-way directional thumb pad, scroll wheel, adjustable palm rest, profiles and Synapse software for PC. It provides a clear gaming-oriented layout and support path, but its switch mechanism is mecha-membrane and it depends on software for configuration.

### Razer Tartarus Pro

The Tartarus Pro adds analog optical switches and adjustable actuation. That can suit players who will deliberately configure the extra behavior. It is not automatically better for someone who wants simple digital actions or cross-platform use.

### Azeron ergonomic keypads

Azeron's current keypad range takes a different approach with finger towers and thumb movement controls. It can place many actions close to the fingers, but the shape, setup time and cost differ sharply from a flat mechanical grid. The maker publishes setup guides and sample profiles, which should be reviewed before treating the design as an instant upgrade.

### A true programmable 24-key board

A professional 24-key mechanical pad may be appropriate when the goal is a custom shortcut grid and the user is comfortable building profiles. Confirm rollover, remapping method, onboard memory, switch model and whether the software is still maintained. Do not pay a gaming premium for generic lighting on office hardware.

## Thumb controls change the effective key count

A thumb pad can handle movement or act as additional buttons. That frees the index, middle and ring fingers for actions. It can also feel less precise than keyboard keys for rapid direction changes, depending on the mechanism and player.

Check whether the thumb control is a true analog stick, an eight-way digital pad or a hat switch. Those labels describe different input. A game may see a digital pad as keyboard directions rather than controller movement.

## Software, profiles and onboard memory

Configuration software is part of the product. Check:

1. Supported operating systems.
2. Whether an account or background service is required.
3. Whether mappings remain on the device after software closes.
4. How many onboard profiles are stored.
5. Whether the software can export or back up a layout.
6. Whether updates and manuals are still available from the maker.

Onboard memory is useful when moving between computers or when a tournament setup cannot run personal software. If mappings exist only in a cloud account, the hardware is less independent than it appears.

## Macros and game rules

Remapping one button to another is different from automating a timed sequence. Some games and competitive services prohibit macros that repeat actions or provide an unfair advantage. Hardware capability is not permission.

Use one-to-one mappings unless the game's rules clearly allow more. Accessibility needs may justify a custom setup, but the safest path is still to check the game or tournament policy rather than relying on another player's profile.

## Ergonomics and hand fit

The wrist rest should support a neutral hand position without forcing the wrist upward. A fixed rest that fits one hand can be uncomfortable for another. Check whether it moves, tilts or detaches, and whether the thumb control can be reached without stretching.

Test repeated movement and modifier combinations for a full session. If the hand tenses to avoid accidental presses, the layout is not solving the intended problem. A compact standard keyboard may be more comfortable and more portable.

## What to test during the return window

- Every key, including diagonals on the thumb pad.
- Simultaneous movement and action presses.
- Profile switching after restart.
- Software behavior without administrator access.
- Wrist and thumb comfort over a normal session.
- Cable placement and desk grip.
- Noise if the setup is shared.

## Who should skip a gaming keypad

Skip it if a standard keyboard already feels good, if the main games require many typing commands, or if the keypad software does not support the computer. Console players should assume incompatibility unless the maker names the exact console and mode.

An exact 24-key count is not a reason to compromise on support. A well-documented 25- or 32-input gaming model is usually a safer purchase than an anonymous board with the preferred number in its title.
