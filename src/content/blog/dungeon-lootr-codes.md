## Join ClickBytes, then open Codes

1. Open the official Dungeon Lootr listing and follow its ClickBytes community link.
2. Join that community on the Roblox account you will use to play.
3. Launch the experience and open Menu, then More and Codes.
4. Paste the string exactly and use the redemption control.

If the game says a community requirement is missing, check the account and community first. Returning to the experience may help a completed membership requirement appear, but it does not make an unrelated group count.

## Know what the loot can and cannot promise

A Luck Potion is a consumable opportunity to improve a run under the game's stated effect. The code alone does not establish a guaranteed item, a guaranteed boss drop or an unlimited duration. Read the potion description and plan to use it while you are actually farming.

A Random GM Blessing should also be read as a random reward. The word random in the listed item matters: a code bundle is not a promise that a specific build-defining blessing will appear. Inspect what was granted before deciding which gear or character to improve.

## When the bundle does not match a guide

Record the code response and the inventory change. That is more useful than assuming the largest amount on a search result must be correct. If the reward is a chest or another container, distinguish the container grant from the items obtained by opening it.

For SILVERINE and TOURNAMENT, the public reports do not agree enough to give a single complete bundle without a caveat. Those limits are kept beside the code so you can decide whether a claim is worth trying without being promised invented quantities.
