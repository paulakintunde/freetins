faq:
  - q: Where do I enter game codes?
    a: It depends entirely on who issued the code. Platform codes and gift cards go into a redemption page on the platform's own website or store menu. Codes issued by a single game go into a box that game builds for itself, usually behind a settings cog or a lobby button. The lookup table on this page gives the exact destination for each one.
  - q: Why is my code not working?
    a: In order of how often it actually happens: the code has expired, a character was mistyped or the case is wrong, the code was already used on that account, you are signed in to the wrong account, a level or progress gate blocks it, the server needs rejoining, the region does not match, or the code belongs to a different game. The failure table on this page covers each one.
  - q: Are game codes case sensitive?
    a: Many are, and the ones that are not still reject a mistyped character. Roblox lists the confusions that cause most failures, including zero read as the letter O, one read as capital I, and eight read as B. Paste the code rather than typing it, and delete any space that came along with the copy.
  - q: How do I redeem Roblox codes on a phone?
    a: Open a browser rather than the app. Roblox states that redemption is not available in the standard mobile app or on consoles, so an iPhone or Android player has to sign in to the redemption page in a browser. Samsung Galaxy is the single exception, with a Redeem tile on the More page inside the app itself.
  - q: Can I redeem the same code twice?
    a: Almost never. Roblox virtual item codes redeem once per account, and PlayStation voucher codes are single use across every account. If you already own the item, some publishers let you pass the code to someone else instead. Check your inventory or your in game mail before deciding a code has failed, because a silent success looks identical to a failure.
  - q: Do game codes expire?
    a: Yes, and most of them expire without warning and without any announcement. Roblox states that a promo code past its window cannot be redeemed at all. Publishers rarely publish an end date up front, which is why a code that worked for somebody an hour earlier can return a plain invalid message for you with no explanation attached.
  - q: Why did nothing appear after the code was accepted?
    a: Look in the right place before retrying. Roblox delivers virtual items into a specific inventory category rather than into the game you were playing. HoYoverse delivers code rewards by in game mail, which itself expires. Xbox installs redeemed content automatically and shows it in the download queue. A second redemption attempt will usually just fail as already used.
  - q: Are code generator sites safe?
    a: No. Roblox publishes a support article stating that free currency and subscription generators do not exist and that these sites are scams. Any page asking for your username, your password or a payment to unlock a code is taking something from you rather than giving anything back. This site will never link one, whatever the reward on offer.

## How to redeem a code

These six steps hold for every row above. The differences come after them.

1. Identify who issued the code. A platform issued it, or a single game did.
2. Sign in to the account that should receive the reward, and check the name on screen.
3. Open the exact destination from the table above for that platform or game.
4. Paste the code rather than typing it, then delete any space before or after.
5. Press the confirm button and wait for the confirmation message.
6. Open the place the reward lands, which is an inventory category, an in game mailbox or a download queue depending on the platform.

### Where the path differs by device

- Roblox splits by device rather than by code. Browser works, standard mobile app does not, and Samsung Galaxy has its own Redeem tile on the More page.
- Xbox splits three ways. Console goes through the guide and the View button, Windows goes through the Xbox app settings, mobile goes through the gear icon on your profile.
- PlayStation splits four ways. The PS5 opens the menu with triangle, the PS4 uses the bottom of the store sidebar, the website uses the profile drop down, and the mobile app uses the menu icon on the right.
- Nintendo splits two ways, and the browser route carries a gate the console route does not: the account must have opened the eShop on a console at least once.
- Epic works the same in the launcher and in a browser, and the older store address now resolves to the store subdomain.

## How to tell a real code from a fake one

{{fakes}}

The test is simple. Trace the code back to the channel the publisher actually posts on. If the trail stops at an aggregator, a compilation video or a comment, the code has no origin and probably never had one. [The evidence tiers behind a Confirmed label](/how-we-verify/) set out why agreement between three list sites still counts for nothing on its own.

Generator sites deserve their own line. There is no mechanism by which a third party site can mint platform currency, and every one of them exists to take an account or a payment. Nothing on Freetins will ever point you at one.
