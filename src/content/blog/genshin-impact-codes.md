## Redeem on the official website

1. Meet the reported Adventure Rank requirement shown by the game or promotion.
2. Open the HoYoverse redemption page linked under Publisher sources.
3. Sign in with the account associated with your character.
4. Select the correct server and confirm the character nickname.
5. Submit a code, then open the game and claim its mail.

The source guide reports Adventure Rank ten for the standard code route. If the portal cannot find your character, check account linking and server selection before assuming the string is invalid. A valid account login and the intended game character are related but distinct checks.

## Use the in-game route when available

The reported in-game path is Settings, Account, Redeem Code. Enter the string, choose the exchange control and collect the corresponding mail. If your platform does not expose that option, use the official web page rather than a third-party login form.

Do not stop at the website's success message. The delivery step is the in-game mailbox, and the reward must be claimed there. Check the character and server you selected if the expected mail does not appear where you are playing.

## Match the item to your plan

Primogems, Mora and experience books serve different purposes. An accepted material bundle may leave the Primogem balance unchanged, which is expected when no Primogems are listed. Read the individual reward before deciding that a claim failed.

A familiar gift string is not a promise of repeated rewards. Prior redemption and the offer's own terms can limit another claim. For livestream promotions, check the announcement's cutoff rather than assuming the code lasts until the associated game update arrives.
