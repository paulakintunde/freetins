## Redeem on the web

1. Open the official Star Rail gift page.
2. Sign in to the HoYoverse account linked to your game.
3. Select the server and confirm the character details.
4. Paste the string and choose Redeem.
5. Open the game and claim the corresponding mail.

The portal can identify a different server's character from the one you have open in the game. Check that selection before submitting and again if a successful claim appears to have gone missing.

## Redeem through the phone menu

The reported in-game route uses the pause or phone menu, then the menu beside your namecard and its Redemption Code option. Enter the string and confirm. The reward is still collected through mail, so finish that step before assuming it was not delivered.

If the option is missing from your platform's interface, use the official website. A guide's screenshot is an aid to finding the control, not a reason to download another app that asks for your HoYoverse credentials.

## Fuel and Jade are separate rewards

Do not read a Fuel grant as extra Stellar Jade. Inspect the named item in inventory and decide when to use it under the game's description. Likewise, experience materials and Credits can arrive in the same bundle without becoming a direct character unlock.

Choose where to spend the resources after claiming them. A code can contribute to a plan, but its reward list does not promise the result of a future random draw or an entire upgraded team.

## If the code is rejected

Copy the string carefully, including any digits that resemble letters. Read whether the response concerns eligibility, a prior claim or an unavailable offer. The usual gift code appearing in another guide is not proof that an account can claim it again.

No deadline is inferred from the age of an announcement. When a source does not establish a publisher cutoff, the table leaves it unrecovered instead of attaching a made-up countdown.
