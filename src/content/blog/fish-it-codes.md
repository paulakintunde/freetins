## Find the store code field

1. Open the official Fish It experience.
2. Select the store or shopping-cart control.
3. Find the code entry field in the store panel.
4. Paste the code, choose Redeem and read any level or eligibility message.

PGG reports a level gate for some entries. If the game specifies that your account is below the requirement, typing the same string again will not resolve it. Continue normal progression and check the requirement for the exact offer you want.

## A Mutation Potion is an item, not a promised fish

Claiming a potion and using it are separate actions. Check your inventory after an accepted code, then inspect its duration and effect before consuming it. A successful redemption does not establish that your next catch must have a rare mutation.

Plan a fishing session around a timed effect rather than activating it while rearranging equipment or leaving the game. This is a resource-use recommendation, not a claim about a hidden drop rate. The game description for the potion should determine what benefit you expect.

## Community rewards and old event codes

Beebom also describes a group reward associated with Fish Atelier. Follow the official game's community link and read the actual prompt before expecting a particular item. Group membership rewards are a separate mechanism from a text code and should be claimed through their own controls.
