## Redeem before starting a run

1. Open the official DOORS experience and stay in the lobby.
2. Open Shop and find the Enter Code Here field.
3. Paste the complete string, preserving its internal spaces.
4. Select Confirm and inspect the reward message.

Use the code field even when the string begins with a slash. A code shaped like a chat command does not mean that chat is its redemption route. Remove accidental leading or trailing spaces, while keeping spaces that are part of the recorded code.

## Knobs, Stardust and Revives do different jobs

The reward column matters more than the number of strings in a list. A tiny Knob reward is not a failed Revive grant, and Stardust is named separately from Knobs. Inspect the game's matching balance after a claim rather than checking only the currency you hoped to receive.

The [official game listing](https://www.roblox.com/games/6516141723/DOORS) also advertises a free Revive for joining LSPLASH's community. That is a group reward, not another redeemable string. Follow the publisher's linked community and read the game's claim conditions.

## What to do with conflicting lists

[Roblox Den](https://robloxden.com/game-codes/doors), [SuperCheats](https://www.supercheats.com/doors-codes) and [RBX Radar](https://rbxradar.com/codes/doors) do not publish the same active set. For example, SuperCheats still lists NO_DATA for 50 Knobs, while Roblox Den marks it expired at 5 Knobs and RBX Radar places it in a disputed section. The table omits NO_DATA from the current set instead of silently choosing the most generous report.

SCREECHSUCKS is shown as 25 Knobs because both Roblox Den and RBX Radar currently report that amount. Older coverage reported 50. Freetins did not redeem it, so the game's own grant message remains the best account-specific check.

If the game rejects a code, read whether it is already used or invalid and check the exact spelling. Older milestone codes can remain in search snippets after their source moves them to an archive. A fresh-looking headline does not establish that the underlying reward is still available.
