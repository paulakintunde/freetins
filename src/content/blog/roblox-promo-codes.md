## How to redeem a Roblox promo code

1. Sign in to the Roblox account you want the item on. A code applies to whichever account is signed in, and the reward cannot be moved afterwards.
2. Open the Redeem Roblox Codes page at roblox.com/redeem. The older roblox.com/promocodes path now redirects there, so both get you to the same single box.
3. Type or paste the code into the Code box and press Redeem.
4. Read the response. Roblox returns a success message, an invalid or expired message, or a message telling you the code has already been used on that account.
5. Open the Avatar section from the site navigation to wear the reward. On the Avatar Editor page, open the category menu that matches the item, such as hats, hair or accessories, then tap the item icon to equip it. If the preview does not change, use the Redraw link underneath it.

Items redeemed this way stay in your inventory permanently. The code expiring later does not take the item back.

## Why is my code not working?

1. It has expired. This is the cause in the overwhelming majority of cases. Roblox retires codes without notice and an expired code never returns.
2. You already redeemed it on that account. Each code is once per account, and Roblox says so in its own troubleshooting steps. Check your inventory before assuming the code is broken.
3. It was limited to one region or one storefront. Several codes on the archive above were only ever valid for a single country or a single retailer's promotion.
4. It belongs to an experience rather than the platform. A code for a specific game goes into that game's own code box, never the redemption page. If that is what you have, follow [the guide to in-game code boxes](/blog/how-to-redeem-game-codes/) instead.
5. A character was wrong. Copy and paste rather than retype, and check for a trailing space.

## Do Roblox promo codes give free Robux?

No, and the honest answer matters more here than a hedge. Roblox has never issued a code that awards Robux, and its own support pages state that free Robux offers, tricks and codes do not exist. Every generator, every code claiming a Robux amount and every site asking for your username plus a verification step is a scam that takes accounts and items. This page will not name or link any of them. The legitimate routes are buying Robux, a gift card, the Premium stipend and selling what you make.
