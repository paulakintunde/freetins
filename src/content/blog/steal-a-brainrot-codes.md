## How to redeem codes in Steal a Brainrot

1. Launch the experience and wait until you have spawned into your own base.
2. Find the button stack down the left side of the screen and press **Codes**. The field used to sit at the bottom of the shop menu, so any guide sending you into the shop is out of date.
3. Type the string into the box that reads **Code Here**. Type it rather than pasting it, because a trailing space from a copy is the most common self inflicted failure.
4. Press **Submit**.
5. Watch the red carpet. Most rewards spawn there as a purchasable brainrot instead of landing in your inventory.

There is no level gate and no rebirth gate on the field itself. There is a cash gate on the reward: a Secret tier spawn can cost tens of millions, appears once, and any player in the server can buy it first. Stand at the tunnel entrance with the money banked before you press Submit. [The full brainrot roster and income figures](/guides/steal-a-brainrot-all-brainrots/) will tell you what a given spawn is worth holding.

## Why is my code not working?

1. **The stock is gone.** This is the top cause by a wide margin. Caps run from a single redemption up to a few hundred, and a popular string empties in minutes.
2. **Your capitalisation is off.** Every code the developer has issued is upper case. Sources disagree over whether the field enforces it, so match the string exactly and remove the question.
3. **You pasted a trailing space or a line break.** Copying from a video description or a chat message usually drags one along.
4. **You have redeemed it before.** Each string works once per account, and plush codes are unique to the buyer.
5. **You are in the wrong game.** Clone titles rank for the same searches. Check the place ID before you blame the code.
