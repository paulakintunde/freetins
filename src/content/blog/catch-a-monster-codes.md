## Redeem through the gift menu

1. Launch the official experience linked in Publisher sources.
2. Select the gift icon at the top right.
3. Open Gift Code and paste the code into its field.
4. Choose Redeem and read the grant message.

The short xp and coin strings can look like ordinary interface labels. They are recorded as code text in the source, so enter them in Gift Code rather than searching for a currency purchase with the same name.

## Claiming an egg is not hatching it

After a successful claim, look for the named egg or chest in the appropriate inventory. Follow the game's own instructions to use it. The claim step and the opening step can be separate, so the absence of a new monster immediately after redemption does not by itself prove a failure.

Do not promise a specific hatch from the word Nightmare, Mythical or another dramatic item name. This list records the container reward only. Any guaranteed contents need their own publisher statement or an explicit description in the game.

## Keep potions for a useful session

Read a Small XP Potion or Small Coin Potion's description before consuming it. Decide what you intend to do while its effect applies, and check whether another effect is already running. The source reward list does not establish how every potion combines with other boosts.

If a code fails, preserve the complete message. A mistyped string, prior claim and withdrawn promotion are different explanations. Retrying through the same menu can correct a typing mistake, but it cannot establish a new reward window.
