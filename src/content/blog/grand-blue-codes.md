## Redeem from Customize Character

1. Launch the official Grand Blue experience.
2. On the title menu, choose Customize Character beneath Play.
3. Locate the Enter Code field and paste the string as written.
4. Select Redeem and inspect the confirmation and your resource totals.

[Pro Game Guides' redemption walkthrough](https://progameguides.com/roblox/grand-blue-codes/) places the field in customization, before normal play. If you are already exploring, return to the appropriate menu instead of searching chat for a command. Preserve punctuation, including the mark at the end of Release!.

## Choose the resource before spending it

Race Rerolls change a different part of your character from Trait Rerolls. Read the label on the reroll control and consider whether you are willing to replace your present result. Redeeming a code adds resources; spending those resources is a separate decision.

The [official listing](https://www.roblox.com/games/18335956021/Grand-Blue) identifies the game as early access and explains that fruit skill levels are retained when swapping fruits. That does not establish a guaranteed chest outcome or make every character change free. Read the relevant confirmation screen before committing.

## Why a listed code may fail

Paste the exact string without a trailing space. Check for an already-redeemed response and ensure you are in the correct experience. An announcement can refer to a changed server version, so returning through the official listing is more useful than repeatedly submitting an unchanged entry.

Do not translate code text or combine parts of different strings. The reward names can be explained in prose, but the redemption field needs the code itself. Keep a screenshot of the result if you want to report a discrepancy with the reward table.
