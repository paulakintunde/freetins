## How to redeem Dragon Soul codes

1. Launch Dragon Soul on Roblox.
2. Press **M** to open the menu.
3. Select **Codes** near the bottom of the menu.
4. Paste the code into the entry field.
5. Select **Claim**.

Codes are case-sensitive. Use the string shown in the table rather than changing it to match the capitalization of a heading.

## What the rewards do

Dragon Balls are collectible items used by the game's wish system. Luck boosts affect reward chances for their stated duration, while an experience boost speeds level progression during its active window.

The `dragonsoul` reward is described as a three-hour experience boost by the current references. Activate a timed boost when you can play, not immediately before leaving the game.

## Why a Dragon Soul code may fail

**The menu is not open.** Press M before looking for the code panel.

**The code has rotated out.** Event and quality-of-life update strings can close without warning.

**Discord verification is required.** Some source lists attach an account-verification requirement to specific rewards.

**The account already used it.** Each code is normally claimable once per account.
