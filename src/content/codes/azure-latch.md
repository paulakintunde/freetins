## How to redeem Azure Latch codes

1. Launch Azure Latch from the official Roblox page.
2. Select **Menu** at the bottom of the screen.
3. Open **Rewards**.
4. Paste the code into the **Code** field.
5. Select **Redeem**.

The three longest strings are easy to mistype. Copy them rather than trying to reproduce repeated words from memory.

## Why a code may fail

**One letter is missing.** Long Azure Latch codes often look like sentences but must remain one uninterrupted string.

**The server predates the update.** Leave and rejoin after a new release.

**The account already used it.** A code is normally single-use for each account.

**The reward rotated out.** Update-linked entries may expire when the next content cycle begins.
