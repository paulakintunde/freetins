## A short list with specific rewards

The current Fisch table contains three long-lived cosmetic or equipment entries: a weapon skin, submarine parts and a bobber. Short event codes are excluded once their stated expiry has passed, even when an old search result still calls them active.

Each row is **listed, awaiting editor verification**. The Fisch reference wiki and a second current tracker agree on the strings, but that is still reporting rather than a Freetins redemption test.

## How to redeem Fisch codes

1. Launch Fisch from the current official Roblox experience.
2. Open **Settings** at the top of the screen.
3. Scroll through the **Other** section.
4. Find the code field near the bottom.
5. Paste the code and press **Enter**.

The current reference says Fisch codes are not case-sensitive. Entering the exact capitalization shown above is still the safest habit and makes troubleshooting easier.

## What the three reward types do

`SCARLET` is recorded as a Scarlet skin for Nate's Blade. It changes the item's appearance; it is not a free fishing rod.

`TemporarySubmarine` grants the component set associated with the submarine. The word “temporary” belongs to the code string and does not mean the redeemed parts disappear from your account.

`CARBON` grants the Carbon bobber. A bobber is a cosmetic fishing item rather than a direct cash or luck payout.

## Why a Fisch code may fail

**The code has an expiry.** Event codes can carry exact closing times and should not be assumed permanent.

**The account already used it.** Most codes can only be redeemed once on an account.

**You opened the wrong Fisch listing.** Roblox has an older experience under the same name. Use the official game link on this page, published by Fisching.

**The field is not visible yet.** Finish loading into the game, open Settings and scroll to the bottom of Other rather than looking for a separate Codes button.
