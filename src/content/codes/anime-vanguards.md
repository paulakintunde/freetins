## How to redeem Anime Vanguards codes

1. Launch Anime Vanguards from the official Roblox page.
2. Select **Profile** on the right.
3. Open **Codes** on the left side of the profile window.
4. Paste one code exactly as listed.
5. Select **Redeem**.

If the profile window does not show the latest controls, rejoin a current server before changing the string.

## Rerolls, shards and keys serve different systems

`Miniupdate1` and `2BVisits` pair Trait Rerolls with Memoria Shards. The milestone code reports the larger quantity, but neither code guarantees a preferred trait.

`Prepare` grants a Red Key rather than rerolls or shards. A key is access to its named content, not a direct unit reward. Keeping these resource types separate prevents the table from implying equal value.

## Why a code may fail

**The string expired.** Milestone and mini-update codes can close without a long warning period.

**The server has not refreshed.** Join a newer server after a patch.

**The code was already used.** Redemption is generally once per account.

**The capitalization is wrong.** `Miniupdate1` uses a lowercase "u," while `2BVisits` mixes a number and capitals.
