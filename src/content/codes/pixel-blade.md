## How to redeem Pixel Blade codes

1. Join the Frost Blade Games Roblox community.
2. Launch Pixel Blade and complete the tutorial.
3. Approach the **Bank** in the lobby.
4. Press **E** to open the code field.
5. Paste one code and select **Claim**.

The community membership and tutorial requirements matter. A new account can see a valid string fail if either step is incomplete.

## What the rewards mean

Coins are a general progression currency. Stardust, Rings, Wishes, Revives, Chests and Godly Potions belong to separate upgrade or reward systems, so they should not be added into one made-up total.

The table preserves the quantities shared by the current sources. Where an archive says only "free rewards," that row is left out of this launch shortlist.

## Why a Pixel Blade code may fail

**Community membership is missing.** Join Frost Blade Games before entering a code.

**The tutorial is unfinished.** The Bank route may not be ready on a brand-new account.

**The code expired.** Milestone strings can remain in third-party archives after the game closes them.

**The server is old.** Rejoin after an update before retrying.
