## How to redeem Ninja Time codes

1. Launch Ninja Time and enter a world.
2. Select **Menu** at the top of the screen.
3. Open **Extra Menu**.
4. Select **Codes**.
5. Paste one code and choose **Redemption**.

Ninja Time was previously known as The Time of Ninja, so an older guide or bookmark may still use that name. The route here follows the current game title.

## What the spins are for

Clan, element and family spins reroll different parts of a character build. A reward described as spins "across the board" applies to those separate pools rather than creating one combined balance.

Use the newest code first if you have limited time. Update strings can close quickly after the next release.

## Why a Ninja Time code may fail

**The code expired.** Update and milestone strings can be removed without a public countdown.

**The wrong menu is open.** The field sits under Extra Menu, not the first settings panel.

**The code was retyped.** Keep every capital letter and exclamation mark.

**The server is old.** Rejoin after an update before treating a newly reported code as dead.
