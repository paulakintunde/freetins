## How to redeem Untitled Boxing Game codes

1. Launch the official Roblox experience.
2. Stay in the lobby rather than entering an active fight.
3. Select **Codes** at the lower-left side of the screen.
4. Paste one code into the text box.
5. Select **Redeem**.

Codes can be lower-case, upper-case or a mix. Paste the exact string and avoid a trailing space.

## Spins and Lucky Spins

A standard Spin rolls a fighting style from the normal pool. A Lucky Spin is a separate reward type intended to improve the quality of that roll. Neither reward lets you select a style directly, and neither guarantees the rarest result.

The code named `100KCASH` is especially easy to misread. Current references report that it grants a Spin despite its name. The table records the reported outcome rather than assuming the string must award 100,000 Cash.

## Why a UBG code may fail

**You are in a fight.** Return to the lobby before looking for the code control.

**The code was retired.** This game leaves a long trail of update and milestone strings, many of which no longer redeem.

**You used it already.** Codes normally grant one reward per account.

**The server has not refreshed.** Rejoin after an update when trying a newly released string.
