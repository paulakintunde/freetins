## The short version

Codes here pay diamonds, the currency that unlocks classes and talent rerolls, and there are only ever a handful of them.

Two rules matter more than the list itself. The redeem menu exists only in the lobby, not during a run, and one of the rewards everyone searches for is not a code at all but a chat phrase typed while fishing.

## How to redeem codes in 99 Nights in the Forest

1. Launch the game and stay in the lobby. Do not start a run.
2. Open the code redemption menu from the lobby interface.
3. Enter the code exactly as printed, in lowercase.
4. Confirm, and check your diamond balance.

For the fishing bonus, start a run, fish, and type the phrase into the Roblox experience chat rather than into any in game menu.

## Why is my 99 Nights code not working?

**You are mid run.** The menu is lobby only. This accounts for most reported failures.

**You typed a chat phrase into the code box.** The fishing bonus is entered in chat. It will never redeem through the menu.

**You capitalised it.** The codes are published lowercase. Copy rather than retype.

**You already redeemed it.** One use per account, and the current set has been available long enough that many returning players have already claimed it without remembering.

## When do new 99 Nights in the Forest codes come out?

Rarely, and not on a schedule. This developer ships large content updates without attaching codes, including the most recent biome refresh, and the codes that do exist have tended to mark events rather than patches. There is no dedicated codes channel on the official Discord, so announcements are the only route.

The honest framing: if you have claimed the current set, there is nothing else to wait for in the short term, and your diamond income comes from chests, day milestones and badges instead. A page that pretends otherwise is padding.

## Getting diamonds without codes

Chests are the reliable source, and the higher tier chests deep in a run pay considerably better than the common ones near camp. Surviving past the major day milestones pays a lump sum, which means a long careful run is worth more than several short aggressive ones. Badge completions are one off but substantial.

## Frequently asked questions

### Why does the code box not appear when I am playing?

Because it only exists in the lobby. The redeem menu is unavailable once a run has started, so if you are already in the forest you need to finish or leave the run before you can enter anything. This is the most common reason players conclude the codes are broken.

### Is "yay fishing" a code?

Not in the normal sense. It is typed into the Roblox experience chat while you are fishing during a run, not into the redeem box, and it pays a small diamond bonus. Almost every competitor page lists it inside the code table, where it will fail every time.

### Are the codes lowercase?

They are published in lowercase by the developer, and the safest approach is to enter them exactly as printed. Lists that render them in block capitals are transcribing rather than quoting.

### What do diamonds actually buy?

Classes, which change how a run plays, and talent rerolls. Diamonds are slow to earn in normal play, which is why a handful of codes is worth more here than in games with generous daily rewards.

### Why has this game not released new codes recently?

Because it never released them often. The most recent major update, the first of the biome refresh releases, shipped with no code attached. Long gaps are normal for this title rather than a sign a page has gone stale.

### Where else do diamonds come from?

Chests found during runs, passing day milestones deep into a run, and badge completions. Between those and the small number of codes, there is no fast route to a large diamond balance.

### Do the codes expire?

The current set has been live for an unusually long stretch by Roblox standards, but expiry is never announced. Redeem when you find them rather than saving them.
