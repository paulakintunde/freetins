## What the current list actually contains

Blade Ball codes usually grant Wheel Spins, although the table may also include a cosmetic reward. The list above is deliberately narrower than many competing lists: it contains the entries that overlap across current references and leaves out `SERPENT`, whose availability is disputed.

Every row is **listed, awaiting editor verification**. That means the code and reward have traceable sources, but a Freetins editor has not redeemed the code in the game. It is useful evidence, not a promise that an old server or previously used account will accept it.

## How to redeem Blade Ball codes

1. Launch Blade Ball from the official Roblox page.
2. Select **Extra** on the top bar.
3. Select **Codes**.
4. Paste the code into the **Redeem Code** box.
5. Select the checkmark.

Preserve every capital letter. If a newly issued code fails, leave the server and rejoin before trying it again; an older server may not have the update that introduced the string.

## Spins, boosts and skins are different rewards

A Wheel Spin gives one attempt on the game's reward wheel. It does not guarantee a sword skin or a specific amount of currency. A luck boost applies to its named system and duration, while a cosmetic code adds the advertised item directly if the account is eligible.

That distinction is why this page records rewards literally. It does not convert a spin into an invented cash value or describe a giveaway entry as a guaranteed katana.

## Why a Blade Ball code may fail

**The code expired.** Blade Ball retains a long historical list, and old articles often keep retired event codes in their main table.

**The account already claimed it.** Codes are generally single-use for each Roblox account.

**A private server is required.** Some sources report that `4BVISITS` is easier to claim in a private server. Try that route before deciding the string is dead.

**The source list is disputed.** Current references disagree on several older entries. Those codes are excluded here rather than padded into the table.

## Frequently asked questions

### Are Blade Ball codes case-sensitive?

Treat them as case-sensitive and paste them exactly as shown.

### Does a Wheel Spin guarantee a rare reward?

No. The code grants the spin, not a chosen result from the wheel.

### Why is SERPENT missing?

One current reference marks it expired while others still list it. It remains outside the table until an editor can resolve that disagreement in the game.

### Where do new codes appear?

The publisher's Discord is linked beside the redemption steps. Updates and milestones are the usual moments to check it.
