## How to redeem SpongeBob Tower Defense codes

1. Launch SpongeBob Tower Defense from the official Roblox page.
2. Reach level 10.
3. Select **Shop** on the left.
4. Open **Codes** and paste the case-sensitive string.
5. Select **Redeem**.

The level gate matters. A code can be current and still remain unavailable on a new account below level 10.

## Why a code may fail

**The account is below level 10.** Continue playing until redemption unlocks.

**The capitalization is wrong.** Preserve the interior capitals in both strings.

**The code rotated out.** The game updates frequently and has a long expired archive.
