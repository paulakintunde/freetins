## Code items you can keep using

Dress to Impress codes unlock wardrobe items rather than temporary currency. Once a code item reaches your account, it remains available for future themes even if the code later retires. The table above focuses on entries that current references agree are still claimable.

Every item is **listed, awaiting editor verification**. The sources agree on the strings and their wardrobe rewards, but Freetins has not redeemed them on a clean account. Seasonal entries that current sources mark inactive are not mixed into this list.

## How to redeem Dress to Impress codes

1. Launch Dress to Impress on Roblox.
2. Select the handbag icon on the left side of the screen.
3. Paste a code into the entry field.
4. Select the checkmark or press **Enter**.
5. Open the code-item wardrobe to equip the reward.

The strings often replace letters with numbers. `CA11MEHHALEY` uses two ones, while `CH00P1E_B4CK_AGA1N` includes zeroes, ones and underscores. Copying is safer than retyping.

## Redeeming is not the same as equipping

A successful code adds an item to your code wardrobe; it does not automatically place the item on the current outfit. Open the wardrobe after redemption, choose the item and then use its toggles or color controls where available.

Some code pieces have fewer customization options than items found in the dressing room. That limitation belongs to the item and is not evidence that the redemption failed.

## Why a DTI code may not work

**A character was substituted.** Zero, capital O, one and capital I are easy to confuse in creator codes.

**The code has retired.** Holiday and collaboration items can close without a long notice period.

**It was already claimed.** Check the code wardrobe before trying the same string repeatedly.

**The server is behind the update.** Rejoin the experience if a newly released item is missing from both the code box and wardrobe.

## Frequently asked questions

### Do Dress to Impress code items expire after redemption?

The redemption window can close, but an item already added to your wardrobe remains available on that account.

### Is PIXIIUWU still listed?

Yes. Current references agree it unlocks a long ballgown dress, so it remains in the source-backed table pending an editor check.

### Where is the code button?

Use the handbag icon on the left side of the in-game screen.

### Can a code unlock VIP?

The entries recorded here unlock named clothing or accessories. They do not grant a VIP subscription.
