## The short version

Every code in this game pays out the same thing: potion chests that improve your luck and roll speed. None of them grant an aura directly, whatever other lists claim.

This page looks different from the competition on purpose. Published lists for this game disagreed wildly in the same week, so codes no editor has tested are listed as awaiting editor verification, with the source beside them, rather than presented as working.

## How to redeem codes in Sol's RNG

1. Launch the game and skip or complete the short tutorial.
2. Open the menu strip on the left edge of the screen.
3. Go to Settings, then switch to the Miscellaneous tab.
4. Use the Redeem Code option to open the entry box.
5. Paste the code and confirm.

That box is shared with the gamepass gift system, which is why players hunting for a separate codes button never find one.

## Why is my Sol's RNG code not working?

**It expired.** Two weeks is the working assumption. This game retires codes faster than almost anything else of its size.

**You are on an old server.** Newly issued codes sometimes only work on updated servers. Rejoining fixes it more often than you would expect.

**The capitalisation is wrong.** Several codes mix cases inside the string, and at least one historic code ended in three exclamation marks.

**You are typing a code from a list that never rechecked it.** Given the disagreement between trackers, this is more likely here than in any other game covered on Freetins.

## When do new Sol's RNG codes come out?

With patches, and the code is usually named after the patch date. That naming convention is the most useful fact on this page, because it means a code can often be worked out from the update date rather than waited for.

Some codes are hidden in the official YouTube channel's videos instead of being announced, which is why community lists diverge: whoever spots the video first has a code nobody else does, and the rest of the trackers copy it late or not at all.

## What the potions actually do

Luck potions raise your chance of a rare roll and haste potions cut the time between rolls. Stacking them is the standard approach for a serious session, and the codes exist to fund exactly that. If you are sitting on chests and waiting for the perfect moment, the moment is a biome event, because the rarest auras are gated behind conditions rather than pure luck.

## Frequently asked questions

### Why are so many codes on this page awaiting editor verification?

Because the trackers disagree and the codes die fast. In the same week, published active lists for this game ranged from one code to six, with no two lists matching. Rather than pick a list and assert it, Freetins publishes every candidate with its source and lists it as awaiting editor verification until an editor has redeemed it in game. A short confirmed list is worth more than a long guessed one.

### How long do Sol's RNG codes last?

About two weeks. One code named after a late February patch was confirmed dead by mid March, roughly a fortnight after issue, and that has held as the rough pattern since. Anything more than two weeks old is probably gone.

### How do I predict the next code?

The codes are named after the patch. The developer has used a date format built from the year, month and day plus an update tag, in both orders. When a patch lands, the code name is frequently derivable from the date before anyone publishes it.

### Where is the code box?

Inside Settings, not in a shop. Open the menu strip on the left of the screen, go to Settings, switch to the Miscellaneous tab and use the Redeem Code option. The same box also accepts gamepass gift codes.

### What do the codes give?

Since late February 2026 every update code has granted the same bundle: potion chests and rare potion chests. Potions cut grinding by improving luck and roll speed, which is the whole game.

### Are codes ever hidden rather than announced?

Yes. Some have been hidden inside videos on the official YouTube channel rather than posted in the Discord. Not every video contains one, so a new upload is a possibility rather than a promise.

### Do codes give auras directly?

No. They give potions and chests that improve your odds. No code has ever granted a specific aura, and any list claiming otherwise is fabricating.
