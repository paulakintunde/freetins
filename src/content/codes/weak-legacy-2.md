## The short version

Codes pay spins, crystal essence and, most usefully, free breathing style and race resets that would otherwise cost Robux.

The resets are the reason this page exists. They apply the moment you redeem, so read the reward before you enter one, because a reset you were not ready for is a reroll you cannot undo.

## How to redeem codes in Weak Legacy 2

1. Launch Weak Legacy 2 and join a server.
2. Wait for the main interface to finish loading fully.
3. Press M, or click the MENU button, to open the menu.
4. Find the Codes section and paste the code into the ENTER YOUR CODE box.
5. Press Redeem and wait for the confirmation message before trying another.

## Why is my Weak Legacy 2 code not working?

**You dropped a character.** Punctuation is part of several code strings in this game, including a trailing exclamation mark on a current code. This is the defining quirk of the title and the most common failure.

**The server had not finished loading.** Entering a code too early fails quietly. Rejoin, wait, retry.

**A space slipped in.** Copying from a formatted list often adds a trailing space. Check the end of the string.

**You already claimed it.** One use per account, and with a large historic list many returning players have claimed more than they remember.

## When do new Weak Legacy 2 codes come out?

With updates and with like milestones, in matched trios: spins, a breathing or art reset, and a race reset. Milestones have run at fifty thousand like intervals, which makes the next milestone code name predictable even when the timing is not.

The archive matters more in this game than most, because the historic list runs to dozens of retired codes, many of them near duplicates that differ only by the update name in the middle. Being able to check whether a string you found is one of those is worth more than another list of live ones.

## Spending resets well

A race reset and a breathing reset are separate rewards and separate codes. If you are rebuilding a character, claim and use them in the right order, since rerolling your race first can change what you want from your breathing style. Fate Spins, when a milestone code grants them, are worth holding until you have a target rather than spending on the first opportunity.

## Frequently asked questions

### Which code resets my breathing style?

The reset codes are named after the update that issued them plus a reset tag, and there is usually a separate one for breathing or art and another for race. Redeeming a breathing reset applies immediately and rerolls your style, so do not enter it until you actually want the change. This is not reversible with the same code.

### Do the codes really contain punctuation?

Yes. At least one current code ends in an exclamation mark that is part of the string, and dropping it will fail the redemption. Several older codes ran past thirty characters with no separators. Copy, never retype.

### Why do some codes have inconsistent capitalisation?

Because the developer is inconsistent. The same game has shipped an all lowercase apology code and a camel case one. There is no rule to infer, which is exactly why exact strings matter more here than in most games.

### How are codes released?

In matched trios with each update: a spins code, a breathing or art reset, and a race reset. Once you know the trio pattern you can tell when a list is incomplete, because a lone reset code almost always has two siblings.

### Is there a level or group requirement?

None reported. The only real requirement is that the game has finished loading. Codes entered on a partially loaded server fail without a clear message.

### Are the first game's codes usable here?

No. Weak Legacy and Weak Legacy 2 are separate experiences with separate lists, and Demonfall is separate again despite the shared Demon Slayer setting.

### What are Fate Spins?

A rarer spin type than the standard ones, issued in much smaller quantities by milestone codes. Save them rather than using them alongside ordinary spins.
