## The short version

Codes pay rerolls, elixirs and skill boxes, and rerolls are the currency that actually matters, both for your own build and for trading.

Before anything else: the code system is locked until you reach Semi-Grade 2. If you cannot see the codes option, that is why, and no amount of retyping will help.

## How to redeem codes in Type Soul

1. Launch Type Soul on Roblox and play until your rank reaches Semi-Grade 2.
2. Open the main menu and select Codes.
3. Paste the code into the Enter Code Here field.
4. Press Redeem.

Copy rather than type. One current code is a full sentence with no spaces and a British spelling in the middle of it, and the game will not forgive a single wrong character.

## Why is my Type Soul code not working?

**You are below Semi-Grade 2.** The gate is real and undocumented in the redeem window.

**You retyped a long string.** The longest codes in this game run past fifty characters. Typing them by hand fails more often than it works.

**The code expired.** Codes track patches and hotfixes, and the current patch cadence is fast.

**You already used it.** One redemption per account.

## When do new Type Soul codes come out?

With patches and hotfixes, and sometimes hidden inside the written update logs rather than announced. Since the game's return the patch cadence has been high, which means the code cadence has been too. Watching the update log directly gets you codes before the trackers copy them across.

## Trading values, and why most value lists are stale

Type Soul has a real player driven economy with no official currency. The community settled on shikai rerolls as the unit of account, and items are quoted in rerolls or in thousands of a base unit. That makes it one of the few games where a values page is genuinely useful rather than decorative.

It also makes staleness obvious. At the time of writing, one prominent value list was carrying items marked as to be determined with a last updated date more than six months old. A values page in this game is only worth publishing if it is dated per row, sourced per row, and refreshed on a stated cadence. Freetins will ship one on that basis or not at all.

## Frequently asked questions

### Why can I not find the codes button?

Because you have not reached Semi-Grade 2. The code system is gated behind rank in this game, and below that rank the option is unavailable. This is the single most common reason a genuinely live code appears not to work for a new player.

### Are Type Soul codes case sensitive?

Yes, and this developer writes long mixed case strings including British spellings and one code that runs to more than fifty characters with no separators. Always copy and paste.

### Is it true that codes are hidden in the update logs?

One of the current codes says so in its own name, and it is accurate. This developer places codes inside written update logs rather than only announcing them, so reading the patch notes is a genuine sourcing route rather than a joke.

### What do codes actually give?

Rerolls, elixirs and skill boxes. The rerolls matter most: they let you reroll a shikai, resurrection, volt or clan without grinding for another chance, which is the entire progression bottleneck of the game.

### Is Type Soul the same as Jujutsu Infinite or Kaizen?

No. All are anime action games with reroll systems, but they are separate experiences with separate codes. Type Soul is published as TYPE://SOUL on Roblox and is Bleach inspired.

### Did the game shut down?

It went quiet for roughly a year and returned in 2026 with the original developer back on the project, bringing Hellverse content and a permadeath system. Patch frequency has been high since the return, which is why codes are arriving regularly again.

### Can I trade the items codes give me?

Rerolls are part of the trading economy in this game, and shikai rerolls function as the community's de facto currency. That makes code rerolls genuinely valuable beyond your own account.
