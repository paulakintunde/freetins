## The Dante and Toji update replaced the older list

Sailor Piece codes expire unusually quickly when a new update arrives. The table therefore starts with the two August 26 Dante and Toji entries rather than carrying forward the much larger Broly, Recode and King archives.

`TojiDanteUpdate` and `Weloveyou` are each reported to grant the same shard, chest, reroll and crate bundle. Both are **listed, awaiting editor verification**, and current references report a level 12,500 requirement.

## How to redeem Sailor Piece codes

1. Launch Sailor Piece from the official Shadowrise Devs Roblox page.
2. Reach the level requirement shown for the current code batch.
3. Open **Settings** from the game interface.
4. Scroll to the **A Secret Code...** field near the bottom.
5. Paste one code and select **Redeem**.

Use a new server after an update. Sailor Piece can replace an entire batch at once, and an older server may not recognize the newest strings.

## Understanding the reward bundle

Power Shards and Passive Shards support different upgrade systems. Secret Chests supply randomized items, while Clan Rerolls change the account's clan outcome.

Aura Crates and Cosmetic Crates are also separate. The reported bundle marks the chests, rerolls and crates as untradeable, so do not assume these items can be transferred to another player.

Because both current codes report the same contents, redeeming the pair should double the total bundle if the account meets the requirement and has not claimed either one before.

## Why a Sailor Piece code may fail

**The account is below level 12,500.** The current entries have a high progression requirement.

**A newer update replaced the batch.** Sailor Piece retires old codes quickly.

**The server is old.** Rejoin or use a newly created server.

**The code's mixed case changed.** Paste `TojiDanteUpdate` and `Weloveyou` exactly.

## Frequently asked questions

### What do the newest Sailor Piece codes give?

Current overlapping sources report 50 Power Shards, 75 Passive Shards, 12 untradeable Secret Chests, 100 untradeable Clan Rerolls, 10 untradeable Aura Crates and eight untradeable Cosmetic Crates from each.

### What level is required?

The newest sources report level 12,500 for both entries.

### Are KINGUPDATEHASARRIVED and RAIDUPDATENOW active?

No current consensus supports keeping them live. Newer sources place them in the expired archive even though an older official description still displayed them.

### Can I trade the code rewards?

The current reward descriptions mark the chests, rerolls and crates as untradeable.
