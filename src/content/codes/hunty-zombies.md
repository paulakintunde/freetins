## A short list because the sources disagree

Hunty Zombie codes can award weapon spins, perk spins and traits, but this is not a page where a long table would be more useful. One current source still lists the two entries above while another has moved the same strings to its expired archive.

## How to redeem Hunty Zombie codes

1. Open Hunty Zombie from the official game page.
2. Select **Codes** on the right side of the screen.
3. Paste one string into the pop-up field.
4. Press **Enter**.

Copy the code rather than typing it. Capital letters and punctuation are part of the string.

## What the rewards change

Weapon spins reroll the weapons available to a character. Perk spins affect passive bonuses, while traits are a separate reroll pool. A large number in a source list does not mean the reward has already been checked on a Freetins account.

## Why a code may fail

**The source list changed.** The two current references disagree, which is why these rows are flagged for human review.

**The server is not current.** Leave the experience, join a fresh server and try again. A private server may also help when the public server has not caught up.

**The account used it already.** Codes are normally single-use per account.
