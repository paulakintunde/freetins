## How to redeem Racket Rivals codes

1. Launch Racket Rivals on Roblox.
2. Select **Shop** at the bottom of the screen.
3. Open **Codes** inside the Shop.
4. Paste the code into the **Enter Code** field.
5. Select **Submit**.

Use the exact uppercase spelling shown in the table. Extra spaces can make an otherwise current code fail.

## Why a Racket Rivals code may fail

**The account is under level 20.** `SCORE` and `CARD` carry a level requirement.

**The code expired after an update.** Short update strings can rotate quickly.

**The code was entered in the wrong panel.** Open Codes from inside Shop.

**The account already claimed it.** A current code will not award the same account twice.
