## Cash, experience and suit codes

Flashpoint: Worlds Collide codes cover several reward types. Some add cash or experience, while others unlock a named speedster suit. The table above keeps the strings and rewards that overlap across the current references rather than importing every seasonal code in a much longer archive.

All entries are **listed, awaiting editor verification**. They are not described as redeemed or guaranteed until a Freetins editor records that event.

## How to redeem Flashpoint codes

1. Join the Varis Studios Roblox community if the code field is locked.
2. Launch Flashpoint: Worlds Collide.
3. Select **Codes** from the controls on the left.
4. Paste one code exactly as listed.
5. Select **Redeem**.

Several codes mix capital letters, numbers and punctuation. Copying is safer than typing, especially for `N3G4T1V3` and `V3X0XZ`.

## Choosing which reward to claim first

Cash and experience help with progression. Suit codes unlock a specific cosmetic or playable speedster variant, so they are useful even when a player does not need another currency boost.

Start with the reward you actually want. Seasonal strings and update rewards can disappear independently, and the table does not claim a shared expiry date.

## Why a Flashpoint code may fail

**Community membership is missing.** Join the developer's Roblox community before retrying.

**The string changed case.** Preserve every letter, number and symbol.

**The code is seasonal.** A source can keep a calendar code in its archive even when the current month does not allow it.

**The server is behind.** Rejoin after a patch before marking a new string invalid.
