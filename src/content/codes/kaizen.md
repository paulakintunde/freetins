## The source-backed Kaizen list

Kaizen codes can provide Lucky Clan Spins and Binding Vow Spins. The current table is intentionally narrower than the long archives elsewhere: it keeps recent strings whose code and reward counts agree across the two references used for this pass.

The official game description also names the newest pair, but the rows remain **listed, awaiting editor verification** because Freetins has not recorded an in-game redemption event for them.

## How to redeem Kaizen codes

1. Launch Kaizen from its official game page.
2. Select the **Settings** cog in the top-left corner.
3. Scroll to **Codes** at the bottom of the panel.
4. Paste a code exactly as shown.
5. Select the red check mark.

The punctuation is part of each code. `MissionBoard!` without its exclamation mark is a different string.

## Clan Spins and Binding Vow Spins

Lucky Clan Spins reroll a character's clan. Binding Vow Spins belong to a separate ability system, so a reward offering eight of each gives eight attempts in both pools, not sixteen interchangeable spins.

Redeem timed rewards only when you are ready to use them. The rows here do not invent boost durations where the current references do not provide one.

## Why a Kaizen code may fail

**The code rotated out.** Kaizen update strings change frequently.

**The punctuation is missing.** Copy the complete string, including `!` where shown.

**The server predates the update.** Rejoin the official experience and try once more.

**The account claimed it earlier.** A valid code can still return an error on a used account.
