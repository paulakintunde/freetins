## How to redeem Da Hood codes

1. Launch Da Hood from the official Roblox page.
2. Select the treasure-chest icon in the lower-left corner.
3. Find the code field at the lower-left of the opened window.
4. Paste the code exactly as listed.
5. Select **Redeem**.

The official experience also requires an account old enough to enter the game. If the experience itself blocks entry, the code field cannot be reached.

## DHC is the stated reward

DHC is Da Hood's in-game cash. Each current code is reported to add 300,000 DHC. The table does not translate that amount into weapons, crates or a real-money value because purchases and prices can change independently.

The two strings carry the same reported reward, but each remains a separate one-time claim.

## Why a code may fail

**The account cannot enter the experience.** Da Hood states that accounts must be at least ten days old.

**The code expired.** Recent additions can replace event strings quickly.

**The account already claimed it.** Each code is generally limited to one redemption.

**An older article is being followed.** `WORLDCUP26` was current earlier in August but is now placed in expired lists by the newest references used here.
