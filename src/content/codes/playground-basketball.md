## How to redeem Playground Basketball codes

1. Open the official Playground Basketball Roblox page and like the experience.
2. Join the **Playground Basketball | Community** Roblox group.
3. Launch the game and remain on the main menu.
4. Select the gift icon at the top of the screen.
5. Paste a code into **ENTER CODE...** and select **REDEEM**.

The like and community requirements matter. A correctly copied code can still fail when either prerequisite has not registered on the account.

## Why a Playground Basketball code may fail

**The account has not joined the community.** Join the official group and rejoin the experience.

**The game has not registered the like.** Complete both publisher prerequisites.

**The update code expired.** Older strings rotate as seasons and events change.

**The server is stale.** Join a fresh server after a code release.
