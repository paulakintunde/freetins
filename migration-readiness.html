P0 · 1

Sitemap advertises 15 URLs that are not live pages

gate B

68 sitemap entries against 53 indexable pages. The 15 extras are the deliberate removals. Submitting this on day one generates 15 immediate Search Console errors on a brand-new property.

Cause: astro.config.mjs builds excludedFromSitemap from routeDefinitions.filter(r => r.noindex). The gone routes live in src/data/gone.ts, so the filter never sees them.

import { goneRoutes } from './src/data/gone.ts';

const excludedFromSitemap = new Set([
  '/internal/',
  ...goneRoutes,
  ...routeDefinitions.filter((route) => route.noindex).map((route) => route.path),
]);

Incremental builds emit the wrong hostname

The fix, in your terms

  • Confirm the 14 unconfirmed channels. A Discord invite, an X handle and a Roblox place ID is ~20 minutes per game — about 5 hours. Alone this moves gate H to 33 %.
  • Re-source codes to the publisher post. method: 'official-source', evidenceTier: 'publisher-confirmed'. At 70 % coverage, gate H reaches ~82 %.
  • Keep aggregator citations as a genuine second tier. A code that only ever appeared on PocketGamer is community-reported. Saying so is what makes the first tier mean anything.
  • Backfill the 59 codes with no confidence and extend the build validator so a code cannot publish without one.
  • Stop treating source-only as failure. INVENTORY.md calls the positioning “a stated method rather than a demonstrated one”. That sets a bar no competitor clears — nobody redeems every code.
  • Drop the two reseller domains and the unattributed pages.dev source.

Publishing cadence

Freeze now. Resume two weeks after cutover.

  • The last content push made gate H worse. Codes rose 44 %, publisher-sourced stayed at zero, needs_human went 38 % → 48 %, and 59 codes shipped with no confidence value. That is scaling a weakness.
  • Attribution. Publishing during a migration makes ranking movement undiagnosable.
  • Volume is not the bottleneck. Gate G already scores 92 %. 38 more game routes are built and correctly gated.

Governing rule: publish at the rate you can source from the publisher, not the rate you can fill a template. The 38 gated routes are an asset — a queue that already knows what it needs.
